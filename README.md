# Kitchen Order Manager

Application web/PWA permettant de gérer les commandes de denrées alimentaires d'une cuisine.

## 🎯 Objectif

Centraliser la gestion des fournisseurs, produits, commandes, factures, livraisons et menus dans une application simple et accessible depuis un téléphone, une tablette ou un ordinateur.

## 👥 Utilisateurs

L'application est destinée principalement à :

* Gestionnaire des achats
* Comptable
* Directrice

Environ 6 utilisateurs pourront utiliser l'application.
